# Changelog

本项目版本号遵循语义化版本（应用层功能版本；数据格式版本见 `state.version`）。

## [1.3.0] - 2026-10-29
### 变更
- 顶部统计区重排版：总支出大数字为主视觉，人均/笔数/人数合并为一条指标栏；
  375px 与 320px 窄屏实测无溢出、无截断。

## [1.2.0] - 2026-10-29
### 新增
- **多行程**：新建/切换/重命名/删除行程（`add_trip`/`switch_trip`/`rename_trip`/`delete_trip`），
  旅伴与账目按行程隔离；记账类命令只作用于当前行程，跨行程 id 操作被服务端拒绝。
### 变更
- 数据结构升级 v1 → v2（`trips[] + activeTripId`）；旧版数据在加载时自动迁移并留档
  `data.json.v1-archived-*`；删除命令 `set_trip` 语义兼容为「重命名当前行程」。

## [1.1.0] - 2026-10-24
### 新增
- 付款人默认记忆：各设备浏览器 localStorage 记录上次所选付款人，下次记账自动选中；
  所记旅伴失效时安全回退。

## [1.0.0] - 2026-10-24
### 新增
- 初始版本：旅伴管理、消费记账（分类/日期/编辑/删除）、AA 平均分摊结算引擎
  （整数分记账 + 余数分垫付优先 + 贪心精确转账匹配）、多设备 2s 轮询同步、
  零依赖双栈（IPv6/IPv4）Python 服务与单文件移动端优先前端。
